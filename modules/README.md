# Teaching modules

A module is a working resource for a particular lesson. Lily Dissection is the first example.

Keep a module's assets, editable source, build scripts, and generated classroom files in its own directory. Its README should explain the learning goal, how to run it, how to rebuild it, and any known limitations. Record third-party sources and licenses before distributing new assets.

The root `index.html` introduces the project and links to available modules. Add a module there when it has a working example. There is no shared authoring runtime yet; reusable tools and a teacher-facing workflow are part of the competition proposal.
