# Vector asset structure

The public module uses an illustrated Stargazer-style lily with separately selectable structures. The editable SVG assets were produced for this project with AI assistance.

Each layer uses a shared 1600 by 1600 coordinate system so the build can stack the structures and move them independently. The main flower includes three petal layers, three sepal layers, six stamen layers, and a pistil. Separate pollen and hummingbird graphics supply the transfer overlay.

The manifest records render order, separation vectors, and pistil sub-regions. Pollination roles come from `build/assemble.py`; the older manifest `group` field is not used for role assignment.

A second, whole-plant scene is included in the asset pack but is not an active teaching module. Adding roots, leaves, or other structures to the learner experience would need its own lesson goal and review.

The purchased 3-D model is separate from these vector assets and has its own commercial license.
